# VPN Bypass для macOS

Нативное приложение для управления доменами, которые должны открываться через
обычный интернет-шлюз в обход OpenVPN. Основано на shell-скрипте, который
разрешает IPv4-адреса доменов и добавляет для них host-route через обычный
интернет-шлюз.

## Возможности

- добавление одного или нескольких доменов;
- удаление и поиск по списку;
- сохранение списка между запусками;
- запуск настройки маршрутов через стандартный запрос прав администратора;
- удаление ранее добавленных маршрутов;
- журнал с результатом для каждого домена и IP.

## Требования

- Mac с Apple Silicon;
- macOS 14 или новее;
- подключённый OpenVPN;
- Command Line Tools for Xcode для самостоятельной сборки.

## Сборка из исходников

```bash
chmod +x build.sh
./build.sh
```

Готовое приложение появится в `build/VPN Bypass.app`.

Чтобы запустить его:

```bash
open "build/VPN Bypass.app"
```

## Важные детали

- Сначала подключите OpenVPN, затем запускайте обход.
- Маршруты строятся для текущих IPv4-адресов домена. После смены сети или IP
  запустите обход снова.
- Приложение использует `dig`, `netstat` и `route`, встроенные в macOS.
- Список хранится в `~/Library/Application Support/VPN Bypass/domains.json`.
- Состояние маршрутов хранится в `/var/tmp/vpn-bypass-<uid>.routes`.
- Изменение маршрутов подтверждается стандартным запросом прав администратора
  macOS. Пароль не сохраняется приложением.

## Структура

- `Sources/main.m` — интерфейс AppKit и управление списком доменов;
- `Resources/vpn-bypass-runner.sh` — добавление и удаление маршрутов;
- `IconMaker.m` — генератор иконки;
- `build.sh` — воспроизводимая сборка и локальная ad-hoc подпись;
- `Tests/domains.txt` — список для безопасной проверки runner через `--check`.
