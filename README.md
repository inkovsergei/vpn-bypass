# VPN Bypass для macOS

Нативное приложение для управления доменами, которые должны открываться через
обычный интернет-шлюз в обход OpenVPN. Основано на shell-скрипте, который
разрешает IPv4-адреса доменов и добавляет для них host-route через обычный
интернет-шлюз.

## Возможности

- добавление одного или нескольких доменов;
- удаление и поиск по списку;
- сохранение списка между запусками;
- запуск настройки маршрутов через стандартный запрос прав администратора;
- автоматический запуск при входе в macOS;
- восстановление маршрутов после подключения VPN, пробуждения и смены сети;
- событийное отслеживание сети без постоянного polling;
- резервная сверка DNS и маршрутов раз в 6 часов;
- удаление ранее добавленных маршрутов;
- журнал с результатом для каждого домена и IP.

## Требования

- Mac с Apple Silicon;
- macOS 14 или новее;
- подключённый OpenVPN;
- Command Line Tools for Xcode для самостоятельной сборки.

## Сборка из исходников

```bash
chmod +x build.sh
./build.sh
```

Готовое приложение появится в `build/VPN Bypass.app`.

Чтобы запустить его:

```bash
open "build/VPN Bypass.app"
```

## Важные детали

- Для ручного запуска сначала подключите OpenVPN.
- Переключатель **Автоматически** один раз устанавливает root-helper и добавляет
  приложение в автозапуск. После этого повторный ввод пароля не требуется.
- Helper запускается при загрузке, реагирует на изменение списка доменов и
  выполняет резервную сверку DNS и маршрутов раз в 6 часов.
- Приложение в фоне обнаруживает подключение VPN, пробуждение и смену сети и
  запрашивает немедленную сверку через системные события System Configuration.
  Постоянного таймера или фонового опроса `netstat` нет.
- Приложение использует `dig`, `netstat` и `route`, встроенные в macOS.
- Список хранится в `~/Library/Application Support/VPN Bypass/`.
- Состояние маршрутов хранится в `/var/tmp/com.github.inkovsergei.vpnbypass.routes`.
- Изменение маршрутов подтверждается стандартным запросом прав администратора
  macOS. Пароль не сохраняется приложением.
- Установленный helper копируется в `/Library/PrivilegedHelperTools/`, принадлежит
  `root:wheel` и принимает только проверенный список доменных имён — команды из
  конфигурации не исполняются.

## Структура

- `Sources/main.m` — интерфейс AppKit и управление списком доменов;
- `Resources/vpn-bypass-runner.sh` — добавление и удаление маршрутов;
- `Resources/auto-mode-installer.sh` — установка фонового launchd-helper;
- `IconMaker.m` — генератор иконки;
- `build.sh` — воспроизводимая сборка и локальная ad-hoc подпись;
- `Tests/domains.txt` — список для безопасной проверки runner через `--check`.
